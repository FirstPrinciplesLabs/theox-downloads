# TheoX 0.1.0

The first installable TheoX release from First Principles Labs.

## Included

- Agent Runtime V2 with a chat-first Study workspace
- Provider, model, and reasoning-effort selection
- Study creation, file tools, scientific computation, and visualization
- Conjecture, Triage, Evolve, and Paper workflows
- Dynamic Research Object history and Study collaboration foundations
- Branded macOS installer and first-run setup

## Platform

- macOS on Apple silicon (M1 or later)

## Installation note

This artifact passed packaged startup and scientific-workflow acceptance tests.
It is not yet Apple-signed or notarized. macOS may require explicit approval in
Privacy & Security before the first launch.
