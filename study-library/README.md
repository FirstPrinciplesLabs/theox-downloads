# TheoX Study Library

Portable Study templates are optional scientific starting points. They are not bundled
with TheoX and installation never executes packaged code.

## Graph Theory Foundation 1.0.0

- 12,359 reconstructible finite graph objects
- 183 populated scientific fields, including 37 Boolean predicates
- zero missing scientific cells
- attached Python computation package and pinned Lean source
- 67 files and 11,521,035 decoded payload bytes

Download `packages/graph-theory-foundation-1.0.0.theox-study.json`, open TheoX's
Study Library, choose **Import package**, inspect the manifest, and install it as a new
independent Study. The package remains visibly unverified until TheoX has a publisher
keyring that can validate its exact bytes.

## Integer Arithmetic Foundation 1.0.0

- 100,000 reconstructible positive integer objects
- 55 exact scientific fields: 30 integer functions and 25 Boolean predicates
- zero missing or non-finite scientific cells
- complete dependency-free Python provider
- optional C++ factorization core parity-tested on 1,000 objects across 11 fields
- Lean foundation with explicit partial coverage and no claimed Python-to-Lean bridge
- 31 files and 5,936,781 decoded payload bytes

Download `packages/integer-arithmetic-foundation-1.0.0.theox-study.json`, open
TheoX's Study Library, choose **Import package**, inspect the foundation, and
install it as a new independent Study. It has no preselected research focus,
target, conjecture, or run history.

## Quantum Measurement Compatibility Foundation 1.0.0

- 11,013 reconstructible unbiased binary qubit-measurement instances
- 51 exact integer and Boolean scientific fields with no floating-point labels
- analytic pair, orthogonal-Pauli-triple, and commuting-triple compatibility certificates
- complete dependency-free Python provider
- optional C++ core parity-tested on 1,800 objects across all three families
- compiled Lean foundation with explicit partial scope and no claimed provider bridge
- 31 files and 899,314 decoded payload bytes

This foundation has no numerical SDP labels and makes no claim about arbitrary POVMs or
higher-dimensional systems. Installation creates an inactive independent Study and does
not execute its attached source.

## Quantum State Geometry Foundation 1.0.0

- 90,204 canonical, reconstructible pure two-qubit projective rays
- 99 complete fields spanning amplitudes, Pauli expectations, correlations, entanglement,
  Bell fidelity, stabilizer structure, and exact predicates
- zero missing or non-finite scientific cells
- complete dependency-free Python provider with an explicit rounding policy for
  transcendental quantities
- optional C++ exact-invariant core parity-tested on 10,000 objects across 23 fields
- compiled Lean representation foundation with explicit partial scope
- 31 files and 5,789,880 decoded payload bytes

The package deliberately excludes mixed and multipartite states. It installs without an
active target, conjecture, or research history and can grow independently after creation.
